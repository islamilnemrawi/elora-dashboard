# Elora Dashboard Android — GitHub Upload

**Important:** Upload the CONTENTS of this folder directly into the ROOT of the `elora-dashboard` repository.

The repository root must contain:

- `app/build.gradle`
- `build.gradle`
- `settings.gradle`
- `gradle.properties`
- `.github/workflows/build-apk.yml`

Do NOT upload the outer `Elora_Dashboard_Android_READY` folder itself as a single folder.

After uploading, open **Actions → Build Elora Dashboard APK** and run the workflow. The generated APK is stored as an artifact named `Elora-Dashboard-debug-apk`.
